## 2. حالات الجهاز

```mermaid
stateDiagram-v2
    state "غير معروف للمنصة" as Unknown
    state "في مخزون وكيل" as Importer
    state "في مخزون محل" as Shop
    state "مملوك لشخص" as Owned
    state "تسجيل ذاتي قيد الانتظار" as SelfWait
    state "بلاغ قيد المراجعة" as Pending
    state "مبلّغ عنه ونافذ (مراقب)" as Active
    state "محظور على الشبكة" as Blocked
    state "مفكّك للقطع" as Parts
    [*] --> Unknown
    Unknown --> Importer: تسجيل الوكيل
    Unknown --> Shop: شراء محل من شخص
    Unknown --> Owned: بيع محل لجهاز جديد
    Unknown --> SelfWait: تسجيل ذاتي مقبول
    SelfWait --> Owned: بعد 30 يوماً
    Importer --> Shop: نقل بالجملة
    Shop --> Owned: بيع
    Owned --> Owned: نقل ملكية
    Owned --> Shop: بيع لمحل
    Owned --> Pending: بلاغ
    Pending --> Owned: رفض
    Pending --> Active: قبول
    Active --> Blocked: أول استخدام على الشبكة
    Active --> Owned: استرداد وإغلاق
    Blocked --> Owned: استرداد وإغلاق وفك الحظر
    Shop --> Parts: شراء للقطع
```

## 3. البلاغ من التقديم حتى الإغلاق

![رحلة البلاغ](../design/screens/lifecycle/light/02-report-journey.png)

التسلسل التفصيلي:

```mermaid
sequenceDiagram
    autonumber
    participant O as صاحب الجهاز
    participant P as المنصة
    participant A as الإدارة
    participant S as بوابة الأمن
    participant T as شركات الاتصالات
    O->>P: تقديم البلاغ مع الأدلة
    P->>P: حماية فورية: رقم بديل وإنهاء الجلسات
    P->>T: إيقاف خط المالك (إن طلب)
    P->>A: البلاغ في قائمة المراجعة مع مستوى الموثوقية
    A->>P: قبول البلاغ
    P->>T: إضافة الجهاز لقائمة المراقبة
    P-->>O: البلاغ نافذ
    Note over P,T: أي فحص أو محاولة بيع أو تركيب شريحة
    T->>P: حدث استخدام: رقم الشريحة والموقع
    P->>S: تنبيه لحظي
    P->>A: تنبيه لحظي
    P-->>O: «المنصة تتابع أمر جهازك»
    S->>P: جلسة تتبّع ثم طلب الحظر
    P->>T: حظر الجهاز
    S->>P: الجهاز مضبوط لدى القسم
    P-->>O: «راجع القسم لاستلام جهازك»
    S->>P: تسليم الجهاز وإغلاق البلاغ
    P->>T: فك الحظر وحذف المراقبة
```

## 5. دورات الحياة الأخرى

### 5.1 الحساب

```mermaid
stateDiagram-v2
    state "جديد" as New
    state "مؤكَّد الرقم" as Phone
    state "مرتبط تلقائياً" as Linked
    state "موثّق الهوية" as Verified
    state "معلّق" as Suspended
    state "محظور" as Banned
    [*] --> New
    New --> Phone: رمز واتساب
    Phone --> Linked: تطابق مع فاتورة محل
    Phone --> Verified: صورة الهوية معتمدة
    Linked --> Verified: صورة الهوية معتمدة
    Verified --> Suspended: مخالفة قيد التحقيق
    Suspended --> Verified: رفع التعليق
    Suspended --> Banned: بلاغ كاذب مثبت
```

### 5.2 المحل

```mermaid
stateDiagram-v2
    state "طلب جديد" as Req
    state "قيد المراجعة" as Review
    state "بحاجة لتعديل" as Fix
    state "موثّق ويعمل" as Active
    state "معلّق" as Suspended
    state "ملغى" as Revoked
    [*] --> Req
    Req --> Review
    Review --> Fix: طلب تعديل
    Fix --> Review: إعادة الإرسال
    Review --> Active: توثيق
    Active --> Suspended: مخالفة أو طلب الأمن
    Suspended --> Active: رفع التعليق
    Suspended --> Revoked: إلغاء نهائي
```

### 5.3 الجهاز على شبكات الاتصالات

```mermaid
stateDiagram-v2
    state "خارج القوائم" as None

    state "تنبيه استخدام" as Used

    state "محظور" as Blocked
    [*] --> None
    None --> Watch: قبول البلاغ
    Watch --> Used: تركيب شريحة
    Used --> Track: طلب الأمن تأجيل الحظر
    Used --> Blocked: حظر تلقائي
    Track --> Blocked: انتهاء الجلسة
    Watch --> None: إغلاق البلاغ
    Blocked --> None: إغلاق البلاغ وفك الحظر
```

### 5.4 التسجيل الذاتي

```mermaid

    Final --> Frozen: بلاغ من شخص آخر
    Frozen --> Cancelled: ثبوت السرقة
    Frozen --> Final: رفض البلاغ
```

## 6. الإيقاع التشغيلي: ماذا يحدث ومتى

| التوقيت | ما يحدث | المسؤول |
|---|---|---|
| **لحظياً** | التنبيهات الأمنية وتنبيهات الشبكة، والإشعارات، ومنع المعاملات المشبوهة، والحماية الفورية عند البلاغ | النظام آلياً، والإدارة، وبوابة الأمن |
| **خلال ساعات** | مراجعة البلاغات وطلبات الإغلاق والهويات والمحلات حسب الأولوية والمهلة | مشرفو الإدارة |
| **يومياً** | مطابقة القوائم مع شركات الاتصالات، والنسخ الاحتياطي، ومراقبة صحة النظام والتكاملات | النظام آلياً، والإدارة |
| **أسبوعياً** | مراجعة المحلات المتعارضة وغير النشطة، ومراجعة تنبيهات السلوك غير الطبيعي | مشرف المحلات والمدير العام |
| **شهرياً** | تقرير التزام المحلات لوزارة الداخلية، والتحديثات الأمنية | مشرف المحلات، وفريق التشغيل |
| **دورياً** | استيراد بلاغات قوى الأمن، واختبار استعادة النسخ الاحتياطي، واختبار الاختراق | الإدارة وفريق التشغيل |
