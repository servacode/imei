# 11 — خطة التنفيذ والإطلاق

> المنتج يُطلق كاملاً (D-18). التطوير الداخلي يمرّ بمراحل لتنظيم العمل والاختبار، **لكن لا يُطلق أي شيء للجمهور قبل اكتمال كل المراحل.** ولا يبدأ أي عمل برمجي قبل إعلان الزبون بدء التنفيذ (D-29).

## 2. مراحل العمل

### المرحلة 0: الاكتشاف والتوثيق ✅
النقاش مع الزبون، وهذه الوثائق.
**مخرجات:** الوثائق 01–12 معتمدة من الزبون.

### المرحلة 1: التصميم
- **تجربة المستخدم:** خريطة الشاشات لكل واجهة، ومخططات أولية، واختبارها مع أشخاص من الفئات الثلاث.
- **التصميم المرئي:** الهوية، ونظام التصميم (ألوان، وخطوط، ومكوّنات)، والتصميم النهائي لكل الشاشات (الموقع، والتطبيق، ولوحة الإدارة)، وقوالب الفاتورة والشهادة وتقرير PDF.
- **التصميم التقني:** تفصيل قاعدة البيانات، وعقد الواجهة البرمجية، وتصميم الأمان، ومواصفات الربط مع شركات الاتصالات.

**مخرجات:** تصاميم معتمدة من الزبون، ووثيقة تصميم تقني.

كل وحدة تُسلَّم مع اختباراتها الآلية، ويراجعها الزبون في بيئة التجريب.

### المرحلة 3: التثبيت والجودة
- اختبار شامل لكل الرحلات على الواجهات الثلاث.
- اختبار الحمل، واختبار الاختراق المستقل، وإصلاح كل الثغرات الحرجة والعالية.
- مراجعة المحتوى والصيغ القانونية.
- **اختبار قبول الزبون:** يجرّب الزبون كل الرحلات ويوقّع على قبولها.

### المرحلة 4: التجريب المغلق
| البند | المقترح |
|---|---|
| النطاق | محافظة واحدة (مثل دمشق) |
| المشاركون | ⚙️ 20–50 محلاً، وعدد محدود من المستخدمين المدعوين |
| المدة | ⚙️ من 3 إلى 4 أسابيع |
| الهدف | اكتشاف المشاكل الحقيقية (سرعة تسجيل المعاملة، ووضوح الشاشات، وضغط العمل على الإدارة) قبل الإطلاق |
| الربط مع الاتصالات | تجربة فعلية إن كانت الاتفاقية جاهزة، وإلا عبر المحاكاة |
| معيار الانتقال للإطلاق | لا أعطال حرجة مفتوحة، وتسجيل المعاملة ضمن الزمن المستهدف، ورضا المحلات المشاركة |

### المرحلة 5: الإطلاق الرسمي
- النشر الكامل للموقع والتطبيقين.
- إعلان رسمي بالتعاون مع وزارة الداخلية عن إلزام المحلات.
- انضمام المحلات **على دفعات حسب المحافظة**، لتجنّب ضغط التوثيق على الإدارة.

## 4. التشغيل بعد الإطلاق

### أهداف زمن الاستجابة للإدارة

| العمل | ⚙️ الهدف |
|---|---|
| تنبيه أمني أو تنبيه شبكة عاجل | المعالجة خلال ساعة (24/7 حسب الاتفاق مع قوى الأمن) |
| مراجعة بلاغ 🟢 | خلال 4 ساعات |
| مراجعة بلاغ 🟡 أو 🔴 | خلال 24 ساعة |
| طلب إغلاق بلاغ | خلال 24 ساعة |
| توثيق هوية | خلال 24 ساعة |
| توثيق محل | خلال 48 ساعة |
| اعتراض | خلال 72 ساعة |

### أعمال دورية
- مطابقة يومية للقوائم مع شركات الاتصالات.
- مراجعة أسبوعية للمحلات المتعارضة أو غير النشطة.
- تحديثات أمنية شهرية، واختبار استعادة النسخ الاحتياطي كل ربع سنة، واختبار اختراق سنوي.

## 5. خطة الوصول للناس

| المرحلة | الإجراءات |
|---|---|
| قبل الإطلاق | الاتفاق مع الوزارة على الإعلان الرسمي، وتجهيز محتوى توعوي (كيف تفحص جهازك، ولماذا تطلب فاتورة موثّقة) |
| الإطلاق | إعلان رسمي، وحملة **«سجّل جهازك قبل ما يضيع»** (كل جهاز يسجّله صاحبه مبكراً يغلق الباب أمام السارق، D-36)، وحملة في مجموعات بيع الموبايلات على فيسبوك وتلغرام، وتغطية إعلامية |
| بعد الإطلاق | تشجيع البائعين على شهادة الفحص في إعلاناتهم (دعاية مجانية للمنصة)، ومتابعة انضمام المحلات حسب المحافظة |

**مشكلة البداية الفارغة:** في البداية لن تكون هناك بلاغات كثيرة. يعالجها: إلزام المحلات الذي يملأ سجل الملكية بسرعة، والتسجيل الذاتي للأجهزة، والتوعية بأن قيمة المنصة تكبر مع الوقت.
