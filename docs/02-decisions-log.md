# 02 — سجل القرارات

يوثّق هذا السجل كل قرار اتُّخذ مع الزبون. أي تغيير لاحق يُضاف كقرار جديد يشير إلى القرار الذي يلغيه، ولا يُحذف القرار القديم.

**المصدر:** «الزبون» = قرار من صاحب الفكرة. «مقترح معتمد» = اقتراح من الشركة قبله الزبون أو بُني عليه دون اعتراض، ويُعرض عليه للتأكيد النهائي عند مراجعة هذه الوثائق.
