# 17 — مسرد المصطلحات

> المرجع الوحيد لمعنى كل مصطلح يُستخدم في الوثائق من 01 إلى 16، وفي الواجهات والرسائل والكود. لكل مصطلح: اسمه العربي المعتمد، واسمه البرمجي في نموذج البيانات أو الواجهة البرمجية إن وُجد، وتعريف واحد، والمصدر الذي جاء منه. وتحسم الوثيقة الكلمات الملتبسة (مثل «موثّق» و«نافذ» و«الموقع»)، وتحدد الكلمات الممنوعة في الواجهات مع بدائلها المعتمدة. عند أي اختلاف في الصياغة بين وثيقتين يُعتمد هذا المسرد، وعند أي اختلاف في القرار يُعتمد [سجل القرارات](02-decisions-log.md).

---

## 1. طريقة الاستخدام

| البند | القاعدة |
|---|---|
| المصطلح العربي | هو الصيغة الوحيدة المعتمدة في الواجهات والرسائل والوثائق. المرادفات المذكورة بين قوسين للفهم فقط ولا تُستخدم في الواجهة |
| الاسم البرمجي | أسماء الجداول والحقول وقيم الحالات والأنواع كما هي في [نموذج البيانات](09-data-model.md) و[التصميم التقني](19-technical-design.md)، ولا يُستخدم غيرها في الكود والواجهة البرمجية. والعلامة † تعني أن القيمة واردة في هاتين الوثيقتين بالصيغة نفسها |
| المصدر | أرقام المتطلبات في [المتطلبات الوظيفية](04-functional-requirements.md)، والقرارات (D-xx)، وأقسام [قواعد العمل](06-business-rules.md) |
| القيم ⚙️ | قيم افتراضية تُعدَّل من لوحة الإدارة، وافتراضياتها من [فهرس الإعدادات](06-business-rules.md#15-فهرس-الإعدادات) |
| الشاشات | تُذكر بمعرّفاتها `S-<AREA>-NN` من [قائمة الشاشات](18-screen-inventory.md) عند الحاجة |

## 2. قواعد الصياغة العامة

| القاعدة | التطبيق |
|---|---|
| **«مؤكَّد» للرقم، و«موثّق» للهوية والمحل** | الرقم يُؤكَّد برمز، والهوية والمحل والوكيل يُوثَّقون بمراجعة الإدارة. لا يُقال «حساب موثّق» دون كلمة «الهوية» (القسم 4.1) |
| **«نافذ» داخلياً، و«فعّال» في النص العام** | الحالة الداخلية للبلاغ «نافذ». والنتيجة العامة تقول «لا توجد بلاغات فعّالة» بالصيغة الثابتة (06 §14) |
| **«مبلّغ عنه» قبل الوصف** | لا يوصف جهاز بأنه «مسروق» أو «مفقود» وحده، بل «مبلّغ عنه: مسروق» أو «مبلّغ عنه: مفقود» (06 §2) |
| **«قوى الأمن الداخلي» رسمياً، و«الجهات المختصة» للجمهور** | في الوثائق والبوابة والتقارير: «قوى الأمن الداخلي» أو «قوى الأمن». وفي نصوص الجمهور: «الجهات المختصة». ولا تُستخدم «الشرطة» |
| **«الموقع» كلمة لمعنيين** | في الواجهة: «موقعك» أو «الموقع الجغرافي» للمكان، و«موقع بصمة» للموقع الإلكتروني. وفي الوثائق يُفهم من السياق، ويُفضَّل «الموقع الإلكتروني» عند الالتباس |
| **لا «تتبّع» في واجهة المواطن والمحل** | «التتبّع» مصطلح محجوز لخريطة الإدارة وقوى الأمن (D-46). وفي غيرها يُقال «متابعة» أو «حالة الطلب» |
| **النتيجة أولاً، دون لوم ولا تهويل** | نبرة [الهوية البصرية](15-visual-identity.md#8-نبرة-الكتابة): أفعال واضحة، ونتيجة ثم تفاصيل، وتذكير بالسلامة في حالات الخطر |

## 4. فكّ الالتباس

### 4.1 «موثّق» ومشتقاتها

استُخدمت الكلمة في الوثائق بخمسة معانٍ. من الآن تُستخدم كل صيغة في مكانها فقط:

| المعنى | الصيغة المعتمدة | أين تُستخدم | الاسم البرمجي | ما لا يُقال |
|---|---|---|---|---|
| حساب اعتُمدت صورة هوية صاحبه | **«موثّق الهوية»**، وفي الواجهة «هويتك موثّقة» وشارة «هوية موثّقة» | كل الواجهات والوثائق | `identity_status = verified`† | «حساب موثّق»، أو «مستخدم موثّق»، أو «موثّق» وحدها |
| مستوى موثوقية البلاغ الأعلى | **«موثوقية 🟢 موثّق»**، دائماً مع الرمز اللوني وكلمة «موثوقية» | لوحة الإدارة وبوابة الأمن **فقط**، ولا يظهر مستوى الموثوقية للمبلّغ ولا للعامة | `trust_level = documented`† | «بلاغ موثّق» في نص عام أو للمبلّغ. وفي الوثائق يُكتب «بلاغ بموثوقية 🟢» |
| محل أو وكيل اعتمدته الإدارة | **«محل موثّق»**، و«وكيل موثّق» | كل الواجهات والوثائق | `shops.status = verified`† | «محل معتمد» أو «محل رسمي» |
| وثيقة صادرة عبر المنصة | الصيغ الثابتة كما هي: «فاتورة موثّقة عبر المنصة»، و«إيصال فحص موثّق» | تذييل الفاتورة وشاشة الإقناع فقط | — | «شهادة موثّقة للملكية» |
| موثَّق بمعنى «مسجَّل ومبرَّر» | «مسجَّل» أو «مكتوب» أو «بسبب مسجّل» | الوثائق الداخلية | — | «قرار موثّق» و«استثناء موثّق» في النصوص الجديدة |

**«مؤكَّد» ليست «موثّق»:** الرقم «مؤكَّد» برمز (`phone_verified_at` رغم أن الاسم البرمجي يقول verified)، وطلب الشركة «مؤكَّد» حين تقرّ باستلامه، والمالك «يؤكد» بلاغ مفوّضه. ولا تُستخدم «مؤكَّد» للهوية أبداً.

### 4.2 كلمات أخرى ملتبسة

| الكلمات | الفرق المعتمد |
|---|---|
| **نافذ / فعّال / فعّالة** | «نافذ» حالة البلاغ الداخلية. «فعّال» يُستخدم فقط في الصيغة العامة «لا توجد بلاغات فعّالة». و«فعّالة» حالة الشهادة غير المنتهية |
| **إغلاق / رفض / سحب / إلغاء** | البلاغ النافذ «يُغلق». والبلاغ قيد المراجعة «يُرفض». والمبلّغ «يطلب الإغلاق» (ومن أسبابه «بلاغ بالخطأ») ولا «يحذف» بلاغه. والمعاملة والشهادة والفاتورة وطلب النقل «تُلغى». ولا يُحذف أي سجل أبداً |
| **حظر / إيقاف / تعليق / تجميد** | «حظر» للجهاز على الشبكة، وللحساب المحظور نهائياً. «إيقاف» لخط صاحب الجهاز ولحساب الموظف. «تعليق» للمحل والحساب مؤقتاً. «تجميد» للمحافظ وللتسجيل الذاتي عند بلاغ |
| **المالك / صاحب الجهاز / المبلّغ / صاحب البلاغ** | «المالك» في الوثائق والقواعد. «صاحب الجهاز» في نصوص الجمهور. «المبلّغ» أو «صاحب البلاغ» لمن يتابع البلاغ |
| **المستخدم المفوّض / الجهة الموثوقة / الرقم البديل** | المفوّض يستخدم جهازاً **بعينه** ويبدأ بلاغه. الجهة الموثوقة تتصرف عن المالك **في كل أجهزته** ببلاغ عاجل. والرقم البديل وسيلة **إشعار** فقط. لا أحد منها يستعيد الحساب (TRUSTED-05، D-81) |
| **إيصال الفحص / شهادة الفحص / الفاتورة / تقرير التاريخ** | الإيصال ثابت للفاحص ويثبت نتيجة لحظة. الشهادة للمالك وحالتها لحظية. الفاتورة لبيع محل وتثبت الشراء. التقرير لقطة مدفوعة لغير المالك بلا بيانات شخصية. ولا شيء منها «سند ملكية» |
| **البلاغ / التنبيه / الإشعار** | «البلاغ» من صاحب جهاز أو قوى الأمن عن جهاز. «التنبيه» للإدارة وقوى الأمن عن حدث. «الإشعار» رسالة لمستخدم |
| **الفحص / التحقق** | «الفحص» لرقم IMEI. و«التحقق» لوثيقة (فاتورة، وشهادة، وإيصال، وتقرير)، وللمطابقة مع السجل المدني |
| **الموقع (المكان) / الموقع (الإلكتروني)** | في الواجهة: «موقعك» و«الموقع الجغرافي» للمكان، و«موقع بصمة» للموقع الإلكتروني |
| **التتبّع / المتابعة** | «التتبّع» للإدارة وقوى الأمن فقط (خريطة وجلسة). وفي غيرها: «المنصة تتابع أمر جهازك»، و«حالة الطلب»، و«تقدّم خطوات الحماية» |
| **المخزون / المخزون الكامل** | «المخزون» أجهزة المحل المسجّلة في السجل (SHOP-13)، مجاني. و«المخزون الكامل» كل بضاعة المحل في برنامج المحاسبة (SHOPPRO-02)، وتدخله أجهزة السجل تلقائياً |
| **الفاتورة** | «فاتورة الجهاز» `TX-` تصدر في معاملة السجل وتُتحقق بـ QR. و«فاتورة نقطة البيع» للإكسسوارات والقطع في البرنامج، دون تحقق عام. و«فاتورة طلب المتجر» تصدرها المنصة باسم المورّد. و«فاتورة الشراء» يسجّلها المحل في حساب مورّده |
| **مورّد المحل / المورّد المعتمد** | «مورّد المحل» أي جهة يشتري منها المحل ويسجّل حسابها في البرنامج (SHOPPRO-04). و«المورّد المعتمد» تاجر جملة متعاقد مع المنصة يبيع عبر المتجر (STORE-03) |
| **الإدارة / المشرف / الدعم الفني** | «الإدارة» فريق المنصة كله. «المشرف» صاحب قرار في قائمة. «الدعم الفني» يستقبل الطلبات ويحوّلها ولا يقرر في البلاغات أو الهويات أو المحلات |
| **قوى الأمن / الجهات المختصة / الشرطة** | «قوى الأمن الداخلي» في الوثائق والبوابة. «الجهات المختصة» في نصوص الجمهور. «الشرطة» لا تُستخدم، وتُكتب أسماء الأقسام كما يُدخلها العنصر («قسم شرطة [...]») |
| **محل / محل الصيانة / الوكيل** | «محل» يشمل كل أنواع النشاط. و«محل الصيانة» محل نوع نشاطه صيانة. و«الوكيل» يشمل المستورد |
| **الشحن / شحن المحفظة / تعبئة الرصيد** | «شحن المحفظة» لإدخال مال إلى محفظة المحل فقط. «تعبئة الرصيد» لبيع رصيد خط سيريتل أو MTN، ولا يُقال «شحن رصيد». و«الشحن» بمعنى التوصيل يأتي في «شركة الشحن» و«مندوب الشحن» وحالة الطلب «مع الشحن» |
| **الرصيد** | «رصيد المحفظة» لمال محفظة المحل. «رصيد الخط» لما يُعبَّأ لرقم الزبون. ولا تُستخدم «الرصيد» وحدها حيث يحتمل المعنيين |
| **المورّد / الوكيل** | «المورّد» يبيع قطعاً وإكسسوارات وملحقات في المتجر. و«الوكيل» يسجّل الأجهزة بأرقامها، وهو وحده يعرض الأجهزة نفسها في المتجر (STORE-13) |
| **الرقم التسلسلي / IMEI** | IMEI للأجهزة ذات الشريحة. والرقم التسلسلي مع الشركة المصنّعة للأجهزة دون شريحة، ومعرّف إضافي لأجهزة آبل |
