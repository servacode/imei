# 09 — نموذج البيانات (تصميم مبدئي)

هذا تصميم منطقي يوضح الكيانات والعلاقات الأساسية، وسيُفصَّل في مرحلة التصميم التقني (أنواع الحقول، والفهارس، والقيود). أسماء الجداول والحقول بالإنكليزية لأنها ستُستخدم كما هي في الكود.

**رموز:** 🔐 حقل مشفّر · #️⃣ بصمة للبحث (HMAC) · 📍 إحداثيات جغرافية

## 2. الأشخاص والحسابات

### `persons` — الأشخاص الطبيعيون
الشخص كيان مستقل عن الحساب: المشتري الذي سجّله المحل موجود هنا حتى لو لم يفتح حساباً بعد.

| الحقل | الوصف |
|---|---|
| id | المعرّف |
| full_name | الاسم الكامل |
| national_id 🔐 #️⃣ | الرقم الوطني (فريد) |
| phone_e164 | آخر رقم موبايل معروف |
| civil_verified_at | آخر تحقق ناجح من السجل المدني (إن وُجد) |
| id_card_status | آخر حالة معروفة للبطاقة: سارية / مفقودة / ملغاة / متوفى |
| created_at | تاريخ الإنشاء |

### `users` — حسابات المستخدمين
| الحقل | الوصف |
|---|---|
| id | المعرّف |
| account_number | رقم الحساب الفريد الثابت (مثل `SY-4K7P92`) |
| person_id | الشخص المرتبط (يُملأ بعد توثيق الهوية) |
| phone_e164 | رقم الموبايل (فريد) |
| phone_verified_at | وقت تأكيد الرقم |
| password_hash | كلمة المرور (Argon2id) |
| governorate_id | المحافظة |
| identity_status | لا يوجد / قيد المراجعة / موثّق / مرفوض |
| status | نشط / معلّق / محظور |

### `identity_verifications` — طلبات توثيق الهوية
`user_id`، وصورتا الهوية (الوجهان، `file_id`)، والاسم والرقم الوطني المصرّح بهما 🔐، والحالة، والمراجِع، والسبب، والتواريخ.

### `otp_challenges` و `sessions`
رموز التحقق (مخزّنة كبصمة، مع الغرض، والصلاحية، وعدد المحاولات)، وجلسات الدخول (الجهاز، والمنصة، وآخر نشاط، والإلغاء).

### `admin_users` — حسابات الإدارة
الاسم، واسم الدخول، وكلمة المرور، ومفتاح التحقق الثنائي 🔐، والدور (مدير عام / مشرف بلاغات / مشرف محلات / دعم فني)، والحالة.

## 4. الأجهزة والملكية

### `devices`
| الحقل | الوصف |
|---|---|
| id | المعرّف |
| brand, model, color | الماركة والموديل واللون |
| tac | أول 8 خانات من IMEI الأول |
| registration_origin | أصل التسجيل: وكيل / جمركة / محل / ذاتي (ثابت) |
| current_owner_type | شخص / محل / وكيل / غير معروف |
| current_person_id / current_shop_id | المالك الحالي |
| public_status | الحالة العامة المحسوبة (لا بلاغات / مسروق / مفقود) |

### `device_identifiers`
`device_id`، والنوع (IMEI / تسلسلي)، والقيمة (فريدة على مستوى المنصة)، والخانة (1 / 2).

### `ownerships` — سجل الملكية
`device_id`، والمالك (شخص أو محل)، والمصدر (بيع محل / شراء محل / نقل / تسجيل ذاتي)، ومرجع المصدر، و`started_at`، و`ended_at` (فارغ للملكية الحالية).

### `authorized_users` — المستخدمون المفوّضون
`device_id`، والاسم، وصلة القرابة، ورقم الموبايل، و`user_id` (إن كان له حساب)، و`person_id` (إن كان يملك رقماً وطنياً، فالقاصر قد لا يملكه)، ومن منح التفويض، وتاريخ المنح والإلغاء.

### `report_owner_confirmations` — تأكيد المالك لبلاغ المفوّض
`report_id`، والمالك، والحالة (بانتظار التأكيد / مؤكَّد / مرفوض / منتهٍ)، و`expires_at`، ووقت التأكيد.

### `self_registrations` — طلبات التسجيل الذاتي
المستخدم، والمعرّفات، والأدلة، ووقت الإقرار القانوني، ونتيجة سجل الشريحة (إن وُجدت)، والحالة (قيد المراجعة / مرفوض / قيد الانتظار / نهائي / مجمّد بسبب بلاغ / ملغى)، و`waiting_until` (نهاية فترة الانتظار)، والمراجِع، والسبب.

### `registration_attempts` — محاولات تسجيل جهاز مسجّل لغير صاحب الطلب
`device_id`، والمستخدم الذي حاول، ووقت المحاولة، وهل أُشعر المالك، والتنبيه المرتبط.

### `ownership_transfers` — طلبات نقل الملكية
`device_id`، والمالك الحالي، ورقم موبايل المستلم، ورقمه الوطني 🔐 #️⃣، والمستلم بعد القبول، والحالة (معلّق / مقبول / ملغى / منتهٍ)، و`expires_at`، ورقم الإيصال.

### `certificates` — شهادات الفحص
`device_id`، والمُصدر، والرمز العام، و`issued_at`، و`expires_at`، والحالة (فعّالة / ملغاة / منتهية)، وسبب الإلغاء.

### `tac_entries` — قاعدة TAC
`tac`، والماركة، والموديل، والمصدر، ومؤكَّد أم لا.

### `disputes` و `dispute_evidence`
المعترض، والإفادة، والأدلة، ورد المبلّغ، والحالة، والقرار، ومن قرّر.

## 7. التكامل مع شركات الاتصالات

### `telecom_operators`
اسم الشركة، وإعدادات الربط (مشفّرة)، والحالة (مفعّل / غير مفعّل).

### `telecom_list_entries` — طلبات المراقبة والحظر
`device_id`، والشركة، ونوع القائمة (مراقبة / حظر)، والإجراء (إضافة / حذف)، والحالة (معلّق / مُرسل / مؤكَّد / فشل)، وعدد المحاولات، و`block_hold_until`، وسبب التأجيل، ومن أجّل.

### `telecom_sim_history_queries` — استعلامات سجل الشريحة
الشركة، و`device_id`، ورقم الموبايل المسؤول عنه 🔐 #️⃣، والسبب والكيان المرتبط (تسجيل ذاتي، أو تعارض، أو اعتراض)، والجواب (نعم / لا)، وتاريخ أول استخدام، ومن طلب الاستعلام، ووقته.

### `telecom_events` — أحداث الشبكة
الشركة، والنوع (استخدام / تكرار IMEI)، وIMEI، ورقم الشريحة 🔐 #️⃣، ووقت الحدث، والموقع التقريبي 📍، والرسالة الأصلية 🔐، ووقت الاستلام.

### `tracking_sessions` — جلسات التتبّع المباشر
`device_id`، و`report_id`، ومرجع طلب قوى الأمن، والسبب، ومن فتحها، و`started_at`، و`ends_at`، والتمديدات، والحالة (نشطة / منتهية / أُوقفت)، وسبب الإيقاف.

### `telecom_location_updates` — تحديثات الموقع من الشبكة
`tracking_session_id` (إن وُجد)، والشركة، و`device_id`، ورقم الشريحة 🔐 #️⃣، والموقع التقريبي 📍، ونصف قطر الدقة، ووقت الرصد، ووقت الاستلام.

## 7.1 التكامل مع الأحوال المدنية

### `civil_registry_queries` — سجل استعلامات السجل المدني
النوع (مطابقة / تعبئة اسم / عرض صورة / حالة بطاقة)، والرقم الوطني 🔐 #️⃣، والغرض والكيان المرتبط (طلب توثيق أو معاملة محل)، ومن طلبه (مشرف أو موظف محل)، والنتيجة (دون تخزين الصورة)، والوقت. صور السجل المدني **لا تُخزَّن** في المنصة (CIVIL-06).

## 7.2 الصيانة والوكلاء والمكافأة

### `repair_jobs` — أوامر الصيانة
`shop_id`، و`device_id`، وصاحب الجهاز (`person_id`) وموبايله، ووصف العطل والحالة، و`check_id`، والموظف المستلم، و`received_at`، والموظف المسلِّم، و`delivered_at`، والمستلِم عند التسليم، والحالة (مستلم / قيد الصيانة / جاهز / مسلَّم / متأخر).

### `board_replacements` — استبدال اللوحة الأم
`repair_job_id`، و`device_id`، وIMEI القديم، وIMEI الجديد، ونتيجة فحص الرقم الجديد، والموظف، والوقت.

### `importers` و `importer_members` — الوكلاء والمستوردون
اسم الشركة، والسجل التجاري، وإجازة الاستيراد أو الوكالة، والمحافظة، والعنوان، والموقع 📍، والحالة (قيد المراجعة / موثّق / معلّق)، والموظفون وصلاحياتهم.

### `import_batches` — دفعات التسجيل بالجملة
`importer_id`، والملف المرفوع، وعدد الأسطر المقبولة والمرفوضة، وتقرير الأسطر المرفوضة، ومن رفعها، ووقتها.

### `wholesale_transfers` و `wholesale_transfer_items` — النقل بالجملة لمحل
`importer_id`، و`shop_id`، والأجهزة، والحالة (بانتظار تأكيد المحل / مؤكَّد / مرفوض / ملغى)، وأوقات الإرسال والتأكيد.

### المكافأة
حقلان في `reports`: `reward_amount` (اختياري، بالليرة السورية) و`reward_updated_at`. المنصة لا تسجّل استحقاقاً ولا دفعاً (D-50).

## 7.3 المصادر الرسمية والخارجية

### `police_imports` — دفعات استيراد بلاغات قوى الأمن
الملف، والمرجع، وعدد الأسطر المقبولة والمرفوضة، وتقرير الرفض، ومن رفعها، ووقتها.

### `gsma_checks` — نتائج الفحص الدولي
IMEI، والنتيجة، ووقت الاستعلام، وانتهاء صلاحية الحفظ المؤقت.

### `customs_lookups` — حالة التسجيل لدى الهيئة الناظمة
IMEI، والحالة (مسجّل / غير مسجّل)، وتاريخ التسجيل، ووقت الاستعلام.

### `compliance_reports` — تقارير التزام المحلات
الفترة، والمحافظة، وملفا PDF وExcel، والمراجِع، وحالة الإرسال، ووقت الإحالة.

## 7.4 بوابة قوى الأمن وحماية لحظة السرقة

### `police_units` و `police_users` — جهات الأمن وعناصرها
الجهة (الإدارة المركزية أو قيادة محافظة)، والنطاق (المحافظات)، والعناصر (الاسم، والرتبة أو الصفة، والرقم الوظيفي، والدور: مسؤول / عنصر، ومفتاح التحقق الثنائي 🔐، والحالة، ومن أنشأ الحساب).

### `police_case_lookups` — بحث الأمن بالرقم الوطني
العنصر، والرقم الوطني 🔐 #️⃣، ورقم القضية، والسبب، والوقت.

### `seized_devices` — الأجهزة المضبوطة
`device_id`، والجهة الحافظة (القسم)، والعنصر، ووقت الضبط، وحالة صاحبه (مبلّغ / مسجّل / غير معروف)، ووقت إشعار صاحبه، ووقت التسليم ولمن.

### `alternate_contacts` — الأرقام البديلة
`user_id`، و`report_id`، والرقم البديل 🔐، ووقت تأكيده، ونشط أم لا، ووقت استعادة الرقم الأصلي.

### `line_suspension_requests` و `wallet_freeze_requests`
`report_id`، والمزوّد (شركة اتصالات أو محفظة أو بنك)، ورقم الخط 🔐، ومن طلب (صاحب الجهاز أو جهة موثوقة)، والحالة (مُرسل / منفّذ / فشل)، والأوقات.

### `wallet_providers` — مزوّدو المحافظ والبنوك
الاسم، والنوع، وإعدادات الربط 🔐، ومفعّل أم لا.

### `trusted_contacts` — الجهات الموثوقة
`user_id`، والجهة (`user_id` للجهة الموثوقة)، والاسم، والحالة (بانتظار القبول / نشطة / ملغاة)، والأوقات.

### `data_access_events` — من اطّلع على بياناتي
`person_id`، والجهة المطّلعة (محل / إدارة / أمن)، والغرض والكيان المرتبط، والوقت، و`visible_from` (موعد ظهوره للمستخدم، لسرية التحقيق).

## 7.5 الخدمات التجارية

| الجدول | الوصف |
|---|---|
| `suppliers` | المورّدون المعتمدون: البيانات، والعمولة، والحالة |
| `products` و `product_categories` | المنتجات وأقسامها، مع علامة «صنف ممنوع» للأقسام المحظورة |
| `store_orders` و `store_order_items` | طلبات المتجر: المحل، والعنوان، والدفع، والحالة |
| `ad_campaigns` و `ad_placements` و `ad_stats` | الحملات، والأماكن، والجمهور، والمراجعة، والمشاهدات والضغطات (مجمّعة) |
| `subscription_plans` و `subscriptions` | الباقات واشتراكات المحلات والشركات وتواريخها |
| `shoppro_*` | بيانات أدوات المحل المدفوعة (المخزون، والمحاسبة، والديون، والكفالات، والفروع)، معزولة لكل محل |
| `history_reports` | التقارير الصادرة: IMEI، ومن طلبها، ولقطة المحتوى، والدفع |
| `api_clients` و `api_usage` | الشركات المرتبطة، ومفاتيحها 🔐، وحصصها، واستخدامها |
| `payments` و `refunds` | المدفوعات بكل طرقها، والمرجع، والتأكيد، والاسترداد |

## 8. البنية المشتركة

| الجدول | الوصف |
|---|---|
| `files` | كل الملفات المرفوعة: مفتاح التخزين، والنوع، والحجم، وبصمة SHA-256، وبصمة الصورة، والرافع |
| `notifications` | المستلم، والقناة، والقالب، والمحتوى، والحالة، والمحاولات، وأوقات الإرسال والتسليم |
| `message_templates` | قوالب رسائل واتساب والإشعارات |
| `governorates`, `areas` | المحافظات الأربع عشرة ومناطقها |
| `settings` | الإعدادات القابلة للتعديل ⚙️: المفتاح، والقيمة، والنوع، والحد الأدنى والأعلى، والوصف ([فهرس الإعدادات](06-business-rules.md#15-فهرس-الإعدادات)) |
| `settings_history` | كل تغيير في الإعدادات: القيمة السابقة والجديدة، ومن غيّر، والسبب، والوقت، لإمكانية الرجوع |
| `audit_logs` | سجل التدقيق (للإضافة فقط): الفاعل، والإجراء، والكيان، والسبب، والعنوان، والوقت |

## 9. ملاحظات تصميمية

- **قاعدة البيانات:** PostgreSQL مع إضافة PostGIS للبيانات الجغرافية، مثل حساب بُعد العملية عن المحل وعرض الخرائط.
- **عدم الحذف:** الكيانات الأساسية (الملكية، والمعاملات، والبلاغات، والفحوص) لا تُحذف، بل تتغير حالتها.
- **الحالة العامة للجهاز** تُحسب من البلاغات وتُخزَّن للسرعة، ويُعاد حسابها عند كل تغيير في بلاغ.
- **البحث بالرقم الوطني** يتم عبر البصمة (#️⃣) دون فك التشفير.
