# تصاميم الشاشات — بصمة

> صور تصميم ثابتة للعرض، وليست برمجة للمنصة. كل شاشة بالثيمين الفاتح والغامق، ومبنية على [الهوية البصرية](../docs/15-visual-identity.md) ورموز التصميم المركزية في `styles/tokens.css`.

لإعادة التوليد: `cd design && npm install && npm run build`
