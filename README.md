# منصة فحص وتوثيق أجهزة الموبايل عبر IMEI — سوريا

> **اسم العمل:** «بصمة» (قابل للتغيير لاحقاً)، والهوية البصرية في [الوثيقة 15](docs/15-visual-identity.md).

## نبذة

منصة وطنية في سوريا تتيح لأي شخص التحقق من حالة جهاز موبايل عبر رقم IMEI قبل شرائه، وتتيح لأصحاب الأجهزة الإبلاغ عن أجهزتهم المسروقة أو المفقودة. وبالتعاون مع قوى الأمن الداخلي، تُلزم المنصة محلات الموبايلات بتوثيق كل عملية بيع وشراء باسم الطرف الآخر ورقمه الوطني، فتصبح **سجلاً وطنياً لملكية الأجهزة**.

## حالة المشروع

| المرحلة | الحالة |
|---|---|
| الاكتشاف والنقاش مع الزبون | ✅ مكتملة |
| توثيق الأساسات (هذه الوثائق) | 📝 مسودة أولى — بانتظار مراجعة الزبون |
| استكمال النقاش مع الزبون | ⏳ جارٍ |
| التصميم التقني التفصيلي وتصميم الواجهات | — |
| التطوير والاختبار | 🔒 لا يبدأ قبل إعلان الزبون بدء التنفيذ (D-29) |
| التجريب المغلق ثم الإطلاق الرسمي | — |

**الواجهات:** الموقع، وتطبيق آيفون، وتطبيق أندرويد، بالحساب نفسه وبالوظائف نفسها لكل المستخدمين، إضافة إلى لوحة إدارة مستقلة، وبوابة قوى الأمن، وبوت واتساب، والفحص برسالة SMS. وتتضمن خدمات تجارية اختيارية (متجر، وإعلانات، وأدوات مدفوعة) لا تمس مجانية الخدمات الأساسية.

## المبادئ الحاكمة

1. **منتج كامل عند الإطلاق:** لا توجد «نسخة أولى مصغّرة». كل الميزات المعتمدة جاهزة يوم الإطلاق، ويسبقه تجريب مغلق.
2. **الثقة أولاً:** لا يُنشر أي بلاغ ولا يُغلق إلا بقرار من الإدارة أو قوى الأمن.
3. **الخصوصية:** لا تُكشف هوية الفاحص ولا موقعه لصاحب الجهاز، ولا يرى المحل إلا معاملاته.
4. **السلامة:** المنصة لا تدفع أحداً إلى مواجهة أحد. التواصل يتم حصراً عبر المنصة والإدارة، والملاحقة من اختصاص قوى الأمن.
5. **العربية أولاً وملاءمة الواقع السوري:** واجهة عربية بالكامل، وتعمل جيداً مع الإنترنت الضعيف والأجهزة المتواضعة.
