# منصة فحص وتوثيق أجهزة الموبايل عبر IMEI — سوريا

> **اسم العمل:** «بصمة» (قابل للتغيير لاحقاً)، والهوية البصرية في [الوثيقة 15](docs/15-visual-identity.md).

## نبذة

منصة وطنية في سوريا تتيح لأي شخص التحقق من حالة جهاز موبايل عبر رقم IMEI قبل شرائه، وتتيح لأصحاب الأجهزة الإبلاغ عن أجهزتهم المسروقة أو المفقودة. وبالتعاون مع قوى الأمن الداخلي، تُلزم المنصة محلات الموبايلات بتوثيق كل عملية بيع وشراء باسم الطرف الآخر ورقمه الوطني، فتصبح **سجلاً وطنياً لملكية الأجهزة**.

## حالة المشروع

| البند | الحالة |
|---|---|
| الاكتشاف والنقاش مع الزبون | ✅ مكتملة (القرارات D-01 إلى D-126)، وشرحها المبسّط في الوثيقة 27 |
| توثيق الأساسات (01 إلى 15) | ✅ مكتمل |
| مراجعة الجاهزية من كل أقسام الشركة | ✅ ثلاث مراجعات: مراجعتا الجاهزية، ثم مراجعة اكتمال السيناريوهات والترابط من 14 زاوية، ثم جولة الاختبار الأخيرة (الوثيقة 16) |
| الترابط والسيناريوهات (26) | ✅ مبادئ الحسم، والآثار المتسلسلة، والقدرات والاستحقاق، وأحداث الحياة، والدورات من البداية إلى النهاية |
| التصميم التقني التفصيلي، والأمن، والخصوصية، والعملية الهندسية، والتشغيل، والمحتوى، ومعايير القبول (17 إلى 25) | ✅ مكتمل |
| تصميم الواجهات (الموقع، والتطبيق، والمحل، والإدارة، وبوابة الأمن) | ✅ الشاشات الأساسية بالثيمين، وقائمة كل الشاشات في الوثيقة 18 |
| التطوير والاختبار | 🔒 لا يبدأ قبل إعلان الزبون بدء التنفيذ (D-29) |
| التجريب المغلق ثم الإطلاق الرسمي | — |

**الواجهات:** الموقع، وتطبيق آيفون، وتطبيق أندرويد، بالحساب نفسه وبالوظائف نفسها لكل المستخدمين، إضافة إلى لوحة إدارة مستقلة، وبوابة قوى الأمن، وبوت واتساب، والفحص برسالة SMS. وتتضمن خدمات تجارية اختيارية لكل محلات الاتصالات والحواسيب (متجر، وإعلانات، وأدوات مدفوعة، ومحفظة المحل وتعبئة الرصيد) لا تمس مجانية الخدمات الأساسية. والحواسيب والأجهزة دون شريحة تدخل السجل بالرقم التسلسلي.

## المبادئ الحاكمة

1. **منتج كامل عند الإطلاق:** لا توجد «نسخة أولى مصغّرة». كل الميزات المعتمدة جاهزة يوم الإطلاق، ويسبقه تجريب مغلق.
2. **الثقة أولاً:** لا يُنشر أي بلاغ ولا يُغلق إلا بقرار من الإدارة أو قوى الأمن.
3. **الخصوصية:** لا تُكشف هوية الفاحص ولا موقعه لصاحب الجهاز، ولا يرى المحل إلا معاملاته.
4. **السلامة:** المنصة لا تدفع أحداً إلى مواجهة أحد. التواصل يتم حصراً عبر المنصة والإدارة، والملاحقة من اختصاص قوى الأمن.
5. **العربية أولاً وملاءمة الواقع السوري:** واجهة عربية بالكامل، وتعمل جيداً مع الإنترنت الضعيف والأجهزة المتواضعة.
